# Breeze Client

**Breeze Client** is a free Windows game launcher. Browse games, install them with one click, launch from your library, chat with friends, and keep track of your playtime — all in one app.

**Website:** [breeze-client.base44.app](https://cinder7832.github.io/Breeze-Client-Website/)

---

## Features

### Games

- **Store** — Browse the catalog, search games, and switch between “all games” and curated **collections**
- **Game pages** — Screenshots, trailers, descriptions, version info, and per-game changelogs
- **Install & update** — One-click installs with pause, resume, and cancel; optional auto-update per game
- **Library** — Everything you own in one place; launch, update, or uninstall from there
- **Downloads** — See active and past downloads in one queue
- **External games** — Add games from your PC that aren’t in the store (point at any `.exe`)
- **Desktop shortcuts** — Create Windows shortcuts that still launch through Breeze (playtime counts)
- **Quick launch** — Pin favorite games to the title bar for fast access
- **Analytics** — Total playtime, most-played games, recently played, and install stats
- **Playtime sync** — Time tracked locally; syncs to the cloud when you’re signed in

### Friends & chat (Socials)

- Add friends, send requests, and see who’s online
- **Direct messages** — Real-time chat with typing indicators, replies, edits, and reactions
- **Group chats** — Create groups, invite people, and manage members
- **Rich chat** — GIFs, emoji, link previews, and pinned messages
- **Message inbox** — Unread alerts show up in the notifications bell
- **Profiles** — Avatar, banner, bio, username, favorite games, and liked games
- **Game activity** — Let friends see what you’re playing (or turn it off in settings)

### Community (on game pages)

- Leave **comments** on games
- Submit **feature ideas** and **bug reports** tied to a specific title
- Discuss and reply on community posts from other players

### Account

- Play as a **guest**, or **sign in** with email/password or **Google**
- Your account ties together friends, chat, playtime sync, profiles, and community posts
- Password reset via email if you forget it

### Notifications & news

- **Announcements** — News and updates from the bell icon in the sidebar
- **Inbox** — Friend and chat notifications in the same drawer
- Desktop notifications for launcher updates, game updates, and new releases (all configurable)

### Settings & personalization

- Choose where games are installed
- Start on Windows login, start minimized, or **close to tray** instead of quitting
- Pick your **start page** (Store or Library) and **launch mode** (windowed or maximized)
- Grid layout — 3 to 6 columns in Store and Library
- **Saved artwork** — Cache cover art for offline browsing
- Check for launcher updates and read the **launcher changelog** from Settings
- Send **bug reports** or **feature suggestions** for the launcher from the sidebar
